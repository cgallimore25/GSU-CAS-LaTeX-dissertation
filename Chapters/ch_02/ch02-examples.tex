	Subsections at this depth (\verb|\subsection{}|) will be displayed in the \hyperlink{toc}{Table of Contents}.

	Though sections at this depth (\verb|\subsubsection{}|) will not be included in the \hyperlink{toc}{Table of Contents}.

	\subsection{Linking and referencing}

	\subsubsection{Chapters}

	The \texttt{cleveref} package allows you to reference chapters using a label that you assign to the Chapter name. 
	For example \Cref{ch:intro} includes some info on document interactions. 
	Notice that the ``1'' to the right of ``Chapter'' is a link that will take you to the beginning of the chapter on Getting Started.

	\subsubsection{Sections}

	You can reference sections using a label assigned in the same way, and in all cases use both numbers and names.
	For example, \nameref{sec:struct}, assigned here the number \Cref{sec:struct}, shows you section and subsection depth. 
	\Cref{sec:abbrevs}, \nameref{sec:abbrevs}, below includes another kind of linking: terms which snap to the \gls{loa} page in your frontmatter.

\section{Content examples}

	\subsection{Abbreviations}\label{sec:abbrevs}

	The \texttt{glossaries} and \texttt{glossaries-extra} packages help you manage the insertion of abbreviations, applied programmatically when inserted with the commands below. 
	Take a look at the \texttt{abbreviations.tex} file to see how they're defined.
	Review the documentation for exhaustive command list.
	
	\begin{verbatim}
		\gls{erp}		    % first instance expanded
		\gls{erp}		    % second + thereafter truncated
		\glspl{erp}		  % plural
		\Acrfull{erp}		% force full expansion, capitalize
	\end{verbatim}
	\nointerlineskip

	Produces: 
	\begin{enumerate*}[label=(\roman*), itemjoin={{, }}, itemjoin={{, }}, itemjoin*={{, and }}]
	\item \gls{erp}
	\item \gls{erp}
	\item \glspl{erp}
	\item \Acrfull{erp}
	\end{enumerate*}.

	\subsubsection{Compositionality}

	The original implementation of this template utilized the \texttt{acronym} package, though the \texttt{glossaries} package allows more flexibility and control over more complicated cases.
	For example, \texttt{glossaries} by default sorts your defined terms alphanumerically before rendering them in your \gls{loa} page. 
	This is more ideal for compositionality in your abbreviations (i.e. using small acronyms as building blocks for others). 
	See the code in \texttt{abbreviations.tex} that generates the following example case and their appearance in the \gls{loa}: 
	\begin{displayquote}  % uses the csquotes package
		``\gls{nmda} elicits responses from \glspl{nmdar}. 
		A variety of neuropsychiatric disease states are associated with \gls{nrh}.''	
	\end{displayquote}

	\subsubsection{Pluralization}

	Sometimes pluralization of acronyms can safely be achieved by appending an ``s'' to the end of the final word.
	This is true in the case of \acrfullpl{erp}. 
	Though other times this pluralization belongs on a different part of the acronym.
	For example, \glspl{roi} more naturally has its first word pluralized. 
	This behavior can be specified by supplying this to the acronym definition in \texttt{abbreviations.tex}.
	

	\subsubsection{Alternate forms}

	Another noteworthy feature of \verb|glossaries| is the ability to define alternate versions of your acronyms for terms used interchangeably.
	This is done using wrapper commands that check for user-defined inputs in definitions.
	For example, in neuroscience: 
	
	\begin{displayquote}
		``\glspl{ap} emitted by a brain cell are often referred to as \altglspl{ap}.''
	\end{displayquote}

	Both of these commands will link back to the defintion of \glspl{ap} in the \gls{loa}.
	This is one of a variety of ways you could possibly implement and customize your management of abbreviations.

	Notice also that the definition for \glsxtrshort{mk801} (\glsxtrlong{mk801}) includes the drug common name and chemical formula in a description field, which, here, \textit{will not} behave as an alternate form that we can reference using the \verb|altgls{}| form command.
	This can be useful when you want to supply supplementary information not intended to be used or referenced back to the \gls{loa} page from the text.
	All of these commands are custom, and can be further modified or built upon to meet your needs.

	\subsubsection{Link control}

	Lastly, you may not want to link every instance of an acronym to the \gls{loa} page.
	You can control this with the starred versions of the commands, which will still apply the same formatting and expansion rules as their non-starred counterparts.
	For example, an instance of \gls*{nmdar} using \verb|\gls*{nmdar}| should have no link.

	\subsection{Citations}

	Here's an example citation of a random paper\supercite{aartsSolutionDependencyUsing2014}.
	Notice that the superscripted number is a link that will take you to the corresponding entry in the bibliography. 
	A custom command \verb|\authoryr{}| is also defined for inline citations, as suggested by \authoryr{aartsSolutionDependencyUsing2014}.
	Examine \texttt{bibliography.bib} to see what information your bibliography \texttt{.bib} file should contain.
	These can be generated by most modern reference managers, for example Zotero or EndNote.

	\begin{displayquote}
		\textbf{Important:} The citation style chosen here is common in fields like neuroscience, and passed formatting review for my committee/department, though you should check with your advisor or department for the preferred style in your field and adjust the bibliography style in \texttt{main.tex} accordingly.
		Also note that in this template, individual entries of the bibliography are single-spaced, but double-spaced between entries. 
		This behavior can be modified by commands in lines \numrange[range-phrase = --]{12}{15} of \texttt{backmatter.tex}. 
	\end{displayquote}

	\subsection{SI units}

	The \texttt{siunitx} package allows us to insert units in a typographically consistent way, ensuring proper height, spacing, and formatting of units (e.g. prevention of linebreaks).
	It's desirable in this context for much the same reasons as \texttt{glossaries}.
	% millimolar is not an SI unit, but we can define it ourselves
	% defined in usercommands.tex as
	% \DeclareSIUnit{\mM}{mM}        % millimolar
	\begin{displayquote}
		``The concentration of drug was \SI[per-mode=fraction]{0.02}{\mol/\L} (\SI{20}{\mM}), which can also be formatted as \SI[per-mode=fraction]{0.02}{\mol\per\L}.
		After a \SI{30}{\minute} period for pharmacological action, mice were placed in a chamber, anesthetized under \qty{3}{\percent} isoflurane, then fixed in a nose cone delivering the same anesthetic mixture. 
		Samples were extracted, tin foil wrapped, and placed in a \SI{-80}{\degreeCelsius} freezer for 25 minutes to achieve firmness.''
	\end{displayquote}
